# 🚀 Инструкция по настройке Telegram Parser

## Шаг 1: Получите API credentials (если ещё не получили)

1. Перейдите на https://my.telegram.org/auth
2. Войдите с номером телефона
3. Перейдите в **"API development tools"**
4. Создайте приложение:
   - **App title**: TeleParser Pro
   - **Short name**: teleparser
   - **Platform**: Other
5. Скопируйте `api_id` и `api_hash`

✅ **Эти данные уже добавлены в секреты проекта**

---

## Шаг 2: Создайте Session String (ОБЯЗАТЕЛЬНО)

### Способ А: Локально на компьютере (рекомендуется)

1. **Скачайте файл** `generate_telegram_session.py` из проекта
2. **Установите Python** 3.8+ (если ещё не установлен)
3. **Установите библиотеку**:
   ```bash
   pip install telethon
   ```
4. **Запустите скрипт**:
   ```bash
   python generate_telegram_session.py
   ```
5. **Следуйте инструкциям**:
   - Введите `TELEGRAM_API_ID` (из my.telegram.org)
   - Введите `TELEGRAM_API_HASH` (из my.telegram.org)
   - Введите номер телефона в формате `+79991234567`
   - Введите код из Telegram
6. **Скопируйте** полученный SESSION_STRING

### Способ Б: Через Replit/Google Colab

Если у вас нет Python локально:

1. Откройте https://replit.com/new/python3
2. Скопируйте содержимое `generate_telegram_session.py`
3. Установите библиотеку: `pip install telethon`
4. Запустите скрипт
5. Скопируйте SESSION_STRING

---

## Шаг 3: Добавьте Session String в проект

1. Откройте проект на https://poehali.dev
2. В чате с Юрой напишите:
   ```
   Добавь секрет TELEGRAM_SESSION_STRING
   ```
3. Вставьте скопированную строку в появившееся поле
4. Сохраните

---

## Шаг 4: Добавьте каналы и запустите парсер

1. Откройте проект
2. Перейдите на вкладку **"Источники"**
3. Нажмите **"Добавить канал"**
4. Введите username канала (без @) или полную ссылку
5. Нажмите **"Запустить парсинг"**

✅ **Парсер заработал!** События будут отображаться во вкладке "События"

## Частые вопросы

**Q: Где взять API credentials?**  
A: https://my.telegram.org/auth → API development tools

**Q: Что делать если Session String истёк?**  
A: Перегенерируйте session string повторив Шаг 2

**Q: Можно ли парсить приватные каналы?**  
A: Да, если ваш Telegram аккаунт является участником канала

**Q: Безопасно ли передавать Session String?**  
A: Session String даёт доступ к вашему Telegram аккаунту. Храните его в секретах проекта и никому не передавайте.

**Q: Сколько каналов можно парсить?**  
A: Неограниченно, но учитывайте лимиты Telegram API (примерно 20 запросов в секунду)

## Техническая поддержка

Если что-то не работает:
1. Проверьте что все 3 секрета добавлены: `TELEGRAM_API_ID`, `TELEGRAM_API_HASH`, `TELEGRAM_SESSION_STRING`
2. Проверьте логи backend функции через Юру: "Покажи логи backend/telegram-parser"
3. Убедитесь что канал существует и доступен
